Dataset: Matbench perovskites, obtained using Matminer 0.10.1; retained locally as matbench_perovskites.json.gz.
Rows: 18,928 crystal structures; 9,646 reduced formulas.
Input: Pymatgen crystal structures.
Target: e_form, calculated DFT formation energy in eV per unit cell.
Family: perovskite materials, relevant to ceramics; this dataset is not a general ceramics or composites collection.
Benchmark: https://matbench.materialsproject.org/
Official repository: https://github.com/materialsproject/matbench
Matminer dataset documentation: https://hackingmaterials.lbl.gov/matminer/dataset_summary.html
Paper: Dunn, A. et al. (2020), Benchmarking Materials Property Prediction Methods: The Matbench Test Set and Automatminer Reference Algorithm, npj Computational Materials 6, 138. DOI 10.1038/s41524-020-00406-3.
Licence: Matbench is released under the MIT licence; the underlying calculations are those of Castelli et al. (2012), Energy Environ. Sci. 5, 9034, reported under CC BY 4.0. The raw file is not bundled here; it is downloaded with Matminer.
